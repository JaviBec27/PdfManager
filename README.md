# PDF Management Tool

A desktop application for managing PDF files, including options to split, merge, extract, sign, and version PDFs. Built using C# and WinForms.

## Features

- **Split PDF**: Split a PDF into multiple smaller PDFs.
- **Merge PDF**: Combine multiple PDFs into a single PDF.
- **Extract Pages**: Extract specific pages from a PDF.
- **Split PDF by pdf**: Split a PDF into multiple smaller PDFs based in file pattern.
- **Version PDF**: Manage different versions of a PDF.
